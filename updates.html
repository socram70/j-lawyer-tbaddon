Latest changes

  • Version 1.10.0
    • The compose popup now opens as its own resizable window next to the compose window, in the same layout as the inbox popup: parties, folders and tags side by side.
    • Compose window: parties can be added to To, CC or BCC with one click; clicking again removes them, the current field is highlighted. New button "Reset recipients".
    • Compose window: case detection now works like in the inbox popup (file number in subject and quoted text, search with the subject, case parties among the recipients) and runs again when recipients or subject change.
    • Case suggestions: the sender's email address is matched against case parties. A file number in the subject takes precedence over address-based suggestions.
    • Archived cases are found in searches, marked as "(archived)" and can be reactivated directly.
    • Context menu dialog for multiple messages: choose between Save, Message only, Attachments only and Message and attachments.
    • New options: skip small images (e.g. signature logos) and selected file extensions when saving attachments separately; close the add-on window after "Save after sending".
    • Fixed: error "tags.0: Expected string instead of undefined" when the tag "veraktet" did not exist yet.
    • Fixed: inline attachments could be taken from the currently displayed message instead of the selected one.
    • Fixed: case detection in the compose window stopped when no cases were cached locally.
  • Version 1.9.7
    • Added English and German localization for the manifest, popups, options, calendar dialog, message-assignment dialog, image editing, context menus and update page.
    • Adjusted the add-on name to the allowed format "j-lawyer.org for Thunderbird".
    • Removed unused activeTab and tabs permissions and moved broad server access to an optional host permission.
    • Migrated Thunderbird message tag handling to the current messages.tags API.
    • Fixed the asynchronous runtime message listener in the message popup.
    • Updated the build package so local agent files are not included in the XPI.
  • Version 1.9.5
    • Fixed: The activity log no longer uses unsafe HTML writes and is readable again in the light layout.
  • Version 1.9.4
    • Fixed: Creation dates for saved emails now reuse existing document metadata and avoid invalid update payloads.
    • Fixed: OCR for newly saved attachments no longer fails because of an internal variable reference.
  • Version 1.9.3
    • Image attachments can now be reordered in the edit dialog.
    • Fixed: After changing the displayed message, image editing uses the attachment of the currently selected message.
  • Version 1.9.x and earlier
    • Added rename templates, improved case lookup and added a combined message and attachment save action.
    • Improved popup layout, window sizing, folder handling, attachment processing and image editing.
    • Added OCR options, document tagging, context menu fixes, compose-window case detection and email template insertion.
    • Added calendar integration, logging, automatic data updates and multiple performance and stability fixes.

Letzte Änderungen

  • Version 1.10.0
    • Das Popup beim Verfassen öffnet sich jetzt als eigenes, skalierbares Fenster rechts am Verfassen-Fenster, im Layout des Posteingangs-Popups: Beteiligte, Ordner und Etiketten nebeneinander.
    • Verfassen-Fenster: Beteiligte per Klick in An, CC oder BCC übernehmen; ein erneuter Klick entfernt sie, das aktuelle Feld ist hervorgehoben. Neuer Button „Empfänger zurücksetzen“.
    • Verfassen-Fenster: Die Aktenerkennung arbeitet jetzt wie im Posteingangs-Popup (Aktenzeichen in Betreff und zitiertem Text, Suche mit dem Betreff, Beteiligte unter den Empfängern) und läuft erneut, wenn sich Empfänger oder Betreff ändern.
    • Aktenvorschläge: Die Absender-Adresse wird mit den Beteiligten der Akten abgeglichen. Ein Aktenzeichen im Betreff hat Vorrang vor Vorschlägen über Adressen.
    • Archivierte Akten werden bei der Suche gefunden, als „(archiviert)“ gekennzeichnet und lassen sich direkt reaktivieren.
    • Kontextmenü-Dialog für mehrere Nachrichten: Auswahl zwischen Speichern, Nur Nachricht, Nur Anhang sowie Nachricht und Anhang.
    • Neue Optionen: kleine Bilder (z. B. Signatur-Logos) und bestimmte Dateiendungen beim separaten Speichern von Anhängen überspringen; Fenster nach „Nach Senden speichern“ schließen.
    • Fehlerbehebung: Fehler „tags.0: Expected string instead of undefined“, wenn das Etikett „veraktet“ noch nicht existierte.
    • Fehlerbehebung: Inline-Anhänge konnten aus der gerade angezeigten statt aus der ausgewählten Nachricht stammen.
